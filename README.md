## Module02 - R for Marine Science

Throughout module 2 we completed two workshops and one keystone exercise (which is in a separate repository). 
Below is a summary of what we completed during these workshops. 

#### Workshop 1: Foundations of Data Science 
Wrangling and Plotting 
- cloning a dataset from GitHub & the housekeeping involved 
- understanding where the projects and scripts are saved onto the computer 
- getting R to read our csv and excel files to begin data wrangling 

Then we installed a package "palmerpenguins" to use as our dataframe to practice data wrangling and plotting. We used: 
- filter() to sift through rows of data 
- arrange() to order sequences 
- and were introduced to pipe |> and mutate().
