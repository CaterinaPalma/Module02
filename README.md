# Module 2: R for Marine Science

Throughout module 2 we completed two workshops and one keystone exercise (which is in a separate repository). 
Below is a summary of what we completed during these workshops. 

#### Workshop 1: Foundations of Data Science 
Wrangling and Plotting 
- cloning a dataset from GitHub & the housekeeping involved 
- understanding where the projects and scripts are saved onto the computer 
- getting R to read our csv and excel files to begin data wrangling 

Then we installed a package "palmerpenguins" to use as our dataframe to practice data wrangling and plotting. We used: 
- filter() to sift through rows of data 
- arrange() to order sequences 
- and were introduced to pipe |> and mutate(). 

#### Workshop 2: Advances Data Wrangling 
Extracting ecological signals from noisy systems 
Throughout this workshop we: 
- practiced how to tidy datasets using the package tidyverse 
- learnt to lengthen our datasets using pivot_longer() - which increases the number of rows 
- widening datasets using pivot_wider() - which decreases the number of rows 
We then used the functions we just learnt, with the palmer penguins data frame. 

Cleaning Datasets - using tivyverse 
We cleaned our datsets, including the names of locations so they are all the same throughout the dataset as well as the date and times. 
Used join_left and join_right to join tables together always remembering to have a common column that linked them together, called a key. 

Take a look at my code and see for yourself how great these functions can be to wrangle, clean and plot data!
